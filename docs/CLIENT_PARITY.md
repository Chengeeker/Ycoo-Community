# 源社区 Lite 功能对照

基准：用户提供 D:/Download/base.apk。仅静态读取 assets/pages 下的 Lua 和 JSON，不安装、不执行其中的更新脚本或远程脚本。界面使用原生 M3，功能数据和链接以该 APK 实际加载的站点移动版为准。

## 已确认的数据源

- 首页：forum.php?mod=guide&view=hot&mobile=2；Comiis 动态标签页 pid=72/28/44 分别为圈子/推荐/关注。
- 推荐模块：plugin.php?id=comiis_app_portal&pid=28&istab=yes&inajax=1，轮播 10、快捷服务 5、热门板块 8、七日排行 15、置顶区 8（2026-10-25 现场快照，数量按服务端配置变化）。
- 推荐信息流：同插件 pid=28&page=N&inajax=1（首页追加 comiis_list=yes，后续页面不追加）；首屏包含真正置顶的 149059 帖。旧版桌面 portal.php 解析不是该客户端的首页契约。
- 社区：forumindex 的 catlist/forumlist；移动版 forum.php?forumlist=1 提供今日/昨日/帖子/会员统计。
- 导读：newthread/hot/digest/new/sofa，index=1&mobile=2。
- 默认头像：站点 data/avatar/noavatar.svg，原始 SVG 保存在 assets/default-avatar.svg。

## 不能以静态检查替代的验收

- 登录、关注、点赞、签到、回复、私信、购买、上传依赖真实账户；没有使用用户账户执行这些写入。
- Flutter 布局测试会模拟系统安全区；真机振感、液态玻璃 GPU、网页文件选择与站点写入仍需设备确认。
- 自动更新脚本的上游 URL 在 APK 中为空，不迁移该客户端的第三方发布地址、作者联系方式或远程脚本执行。
