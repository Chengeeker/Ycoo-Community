# 源社区

Android 源论坛客户端，应用名 **源社区**，包名 **ycoo.net.php**。

基于 Flutter Material 3，直接复用本机 Review 的主题、磨砂顶栏、页面壳、卡片、个性化设置、导航与触感实现。底栏为首页、社区、导读、我的；悬浮底栏可选 Review 使用的液态玻璃效果，MIT 许可见 LICENSE 和第三方声明。

当前版本 **1.0.0+24**。图库中缩略图数量较少时居中排列，数量超出可用宽度时仍可横向滚动。新增消息分类、积分概览与分栏、推广二维码和小黑屋列表，并补充资料设置、任务、勋章、道具等入口；部分站点表单和交互仍需登录后验证。我的页面使用对应功能图标；好友、心情、圈子等可识别的站点导航及社区、导读、版块、签到筛选使用 M3 顶部分栏。修复旧缓存中普通等级显示灰色，以及“我的”页面统计加载时的布局跳变。关注按钮改为扁胶囊并移除加号；等级徽章使用站点默认及用户组实际指定的颜色。帖子卡片按站点内容补充等级颜色、性别与认证标识，收紧正文和统计栏间距并修正默认头像形状。修复启动后已登录用户点击关注时误弹登录页：先等待登录状态确认，确认后直接进入。收紧首页顶部标题和分栏的间距，移除关注两级分栏之间的分隔线及多余的“社区动态”标题。首页关注新增“我的关注、关注版块、好友动态”二级顶栏分栏，各分栏独立读取与缓存；磨砂顶栏边界随分栏调整。修复帖子先显示部分内容、再补入信息导致的跳变；版块置顶帖合并作者、头像和正文摘要，旧的残缺置顶缓存自动重载。修复图库被顶部工具栏压缩、图片与缩略图挤到顶部的问题；主图铺满视口居中，工具栏和缩略图分开定位。新增帖子正文隐藏区/引用/版权声明分区、作者等级和分类补全、已解锁付费信息，以及外链访问选择弹窗。新增网页登录昵称补全、原生每日签到与排行、主题购买确认与解锁后刷新；常用站内内容和标准表单改为原生 M3。云盘使用原生文件列表、搜索、文件夹和基础管理操作，本地存储可从系统文件选择器上传，单文件最大 64MB。

已实现首页圈子/推荐/关注分栏、轮播、热门板块、七日榜和置顶；社区目录、导读、搜索、帖子与回复、收藏/消息和阅读历史；Review 风格原生图库、玻璃按钮、缩略图条、手势动画及保存相册；直链视频播放、主题/字体/触感/悬浮底栏设置。外链先显示继续访问、复制链接、浏览器打开选项；浏览器选项使用内置浏览器，站内帖子仍转原生详情。

原生适配尚未全量完成：独立农场游戏等脚本动作、第三方云存储上传仍需继续适配；注册和特殊安全验证保留站点流程。页面的“复制页面适配信息”仅导出脱敏结构，不包含 Cookie、密码或表单值，可用于反馈尚未支持的插件。

## 开发与打包

- Flutter SDK：D:/flutter_sdk；Java 17：D:/jdk17。
- `flutter pub get`
- `dart analyze --format machine lib test`
- `flutter test --reporter expanded`
- `powershell -File tool/build_release.ps1`

发布脚本使用临时 ASCII 盘符规避 Windows 中文路径的 AOT 编译问题，结束时移除其创建的映射。仅构建 release / android-arm64，检查包名、ABI、签名和对齐后复制 APK 到项目根目录；成功后只保留最新正式 APK，旧 APK 自动清理。构建日志统一写入 build/logs，不在项目根目录输出。

本机 android/key.properties 和 .signing/release.p12 已配置，均不进入版本管理。PKCS12 是指定 BKS 私钥的本机格式转换，证书必须与 BKS 一致。缺失正式签名时构建直接失败，不生成 debug 签名的发布包。

`tool/check_site.py` 用 Python 标准库执行公共接口只读检查。站点当前需要可访问它的网络路线，开发期间由用户在本机代理添加直连规则后访问成功。应用不内置代理、不改 DNS、不固定服务器 IP。

## 当前验收边界

公共站点接口已在开发电脑读取；自动化回归不能替代真机。尚无真实账户登录、私信/收藏列表、实际发布、付费与下载的端到端验收。未连接 ADB 设备，不自动安装。
