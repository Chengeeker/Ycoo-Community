# 源社区

Android 源论坛客户端，应用名 **源社区**，包名 **ycoo.net.php**。

基于 Flutter Material 3，复用 Review 的主题、磨砂顶栏、页面壳、卡片、个性化设置、导航与触感实现。底栏为首页、社区、导读、我的；悬浮底栏可选 Review 使用的液态玻璃效果，MIT 许可见 LICENSE 和第三方声明。

## 开发与打包

- 配置 Flutter SDK 与 Java 17，并将相应命令加入 PATH。
- `flutter pub get`
- `dart analyze --format machine lib test`
- `flutter test --reporter expanded`
- `powershell -File tool/build_release.ps1`

发布脚本使用临时 ASCII 盘符规避 Windows 中文路径的 AOT 编译问题，结束时移除其创建的映射。仅构建 release / android-arm64，检查包名、ABI、Flutter 资源、完整图标字体、签名和对齐后复制 APK 到项目根目录；成功后只保留最新正式 APK，旧 APK 自动清理。构建日志统一写入 build/logs，不在项目根目录输出。

正式签名通过本地 android/key.properties 配置，密钥与配置均不进入版本管理。PKCS12 是指定 BKS 私钥的本机格式转换，证书必须与 BKS 一致。缺失正式签名时构建直接失败，不生成 debug 签名的发布包。

`tool/check_site.py` 用 Python 标准库执行公共接口只读检查。站点当前需要可访问它的网络路线，开发期间由用户在本机代理添加直连规则后访问成功。应用不内置代理、不改 DNS、不固定服务器 IP。

## 当前验收边界

公共站点接口已在开发电脑读取；自动化回归不能替代真机。尚无真实账户登录、私信/收藏列表、实际发布、付费与下载的端到端验收。未连接 ADB 设备，不自动安装。
